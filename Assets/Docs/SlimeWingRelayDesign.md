# Slime + Wing Relay

目标：在一张简约非线性地图中，分别使用史莱姆压缩、灰柱攀爬与翅膀飞行取得三把钥匙；钥匙可按任意顺序收集，全部取得后打开终点门。

## 关卡节奏

1. **中央枢纽**
   - 灰色长地板连接所有路线，允许玩家随时改变钥匙收集顺序。
2. **钥匙 A：压缩低缝（x=-3.5）**
   - 绿色低缝直接连到地面，只有史莱姆压缩后可以进入并取得黄色钥匙。
3. **钥匙 B：灰柱攀爬塔（x=3.4）**
   - 灰柱是无实体碰撞的慢速攀爬触发区；不会压扁、卡住或拉扯史莱姆。
   - 顶部平台放置第二把钥匙。
4. **钥匙 C：低顶飞行段（x=7.25~10.8）**
   - 从蓝色起飞台进入灰色低顶下的飞行段，拍翼滑翔到右侧蓝色平台取得第三把钥匙。
5. **锁门终点（x=13.4）**
   - 紫色门在三把钥匙收齐前保持阻挡；全部收齐后变绿并解除碰撞，进入右侧终点台即通关。

运行时地形由 `SlimeRelayCourse` 创建，便于后续替换为美术预制体而不改变坐标和玩法节奏。

## 颜色说明与通关路线

- **黄色**：可收集钥匙。
- **紫色 / 绿色门**：锁定 / 已开启的终点门。
- **绿色**：史莱姆压缩路径。
- **灰色**：柱子、封顶和路径边界。
- **蓝色**：翅膀起飞与滑翔落点。

路线为：中央枢纽 → 三个钥匙分支（任意顺序）→ 解锁终点门 → 终点台。
